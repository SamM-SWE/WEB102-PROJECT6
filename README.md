
# WEB102 Project 6

A React-based data dashboard developed as part of CodePath's WEB102 Intermediate Web Development course.

This project focuses on building an interactive web application that displays data through reusable components, visualizations, and dynamic user interfaces.

## Demo

![Project Demo](./DEMO.gif)

## Features

- **Data Visualization:** Displays information using charts and graphs powered by Recharts.
- **Interactive Dashboard:** Organizes data into a clean and accessible interface.
- **Component-Based Architecture:** Uses reusable React components for maintainability.
- **Client-Side Routing:** Implements React Router for navigation between pages.
- **Dynamic Rendering:** Uses React to update the interface based on application data.

## Built With

- **React.js** - Frontend JavaScript library
- **JavaScript** - Application logic and functionality
- **CSS3** - Styling and layout
- **Vite** - Development server and build tool
- **React Router** - Client-side navigation
- **Recharts** - Data visualization library

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/SamM-SWE/WEB102-PROJECT6.git
   ```

2. Navigate to the project directory:

   ```bash
   cd WEB102-PROJECT6
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
